# 📈 股价值得买 · A股/港股/美股 估值分析 PWA

输入股票代码 → 自动获取**实时股价、市盈率 PE、市净率 PB、市值**等，
并用一套透明可解释的模型给出**"是否值得买"的量化评分**。支持**手动补充基本面**让结论更准。

纯前端、零服务器、零费用，数据只存本机浏览器，可"添加到主屏幕"当 App 用。

## 二、功能

| 模块 | 说明 |
|---|---|
| 实时行情 | 现价、涨跌额/幅、今开、最高、最低、成交额、换手率、量比、振幅 |
| 估值指标 | 市盈率 PE(TTM) / 静态 PE / 动态 PE、市净率 PB、总市值 |
| 买卖评分 | 综合分 0–100，评级 A/B/C/D，附各维度拆解与结论文案 |
| 手动基本面 | 可填 **ROE / 净利润增速 / 股息率**，填后评分自动纳入"基本面"维度（按股票代码本地记忆） |
| 走势参考 | 自动拉取近 80 日前复权 K 线，计算 MA20 / MA60 与近 20 日涨跌幅 |
| 自选股 | 收藏、一键复查、导出/导入 JSON 备份（localStorage 本地存储） |
| PWA | 离线可用、可安装到桌面、版本更新自动提示 |

## 三、评分模型（透明可复算）

**未填基本面**：综合分 = 估值 40% + 趋势动量 25% + 风险 20% + 流动性 15%
**填写基本面**：综合分 = 估值 30% + **基本面 30%** + 趋势动量 20% + 风险 10% + 流动性 10%

- **估值**：PE(TTM) 分档（<10→100，10–15→85，15–25→70，25–40→50，40–60→32，>60→20；亏损取 15）×0.6
  + PB 分档（<1→100 … >10→25）×0.4。**港股/美股无 PB 数据，则估值仅按 PE 计算。**
- **基本面**：ROE×0.4 + 净利润增速×0.35 + 股息率×0.25（分档：ROE 20%+ 优秀、增速 25%+ 优秀、股息 3–5% 较优）
- **趋势动量**：现价相对 MA20 / MA60（各 ±12）+ 近 20 日涨跌幅（±18 封顶）
- **风险**：日收益年化波动率（<15%→100 …>50%→32）+ 当日振幅
- **流动性**：成交额×0.5 + 换手率×0.25 + 量比×0.25（港股缺换手率/量比时自动降权）

评级：**≥80 优秀 A**｜**65–79 良好 B**｜**50–64 一般 C**｜**<50 谨慎 D**

> 公式全部写在前端代码里，可自行修改权重或分档。

## 四、数据来源

- 行情：腾讯财经公开接口 `qt.gtimg.cn`（GBK 编码，返回头含 `access-control-allow-origin: *`，浏览器可直接 `fetch`）
- K 线：`fqkline`（A股）/ `hkfqkline`（港股）/ `usfqkline`（美股，需带 `.OQ` 等交易所后缀，代码已自动处理）
- 均为**免费、无需 API Key**；接口偶发失效时页面会提示，重试即可。
- 港股/美股为延迟约 15 分钟行情；非交易时段显示最近收盘数据。**数据仅供学习参考，不构成投资建议。**

## 五、部署到 GitHub Pages（独立仓库）

### 1. 建仓库
GitHub 新建仓库（如 `stock-value-app`），**必须设为 Public**（免费版 Pages 不支持私有仓库）。

### 2. 上传文件（保持目录结构）
```
index.html
manifest.webmanifest
sw.js
icons/icon-192.png
icons/icon-512.png
README.md   （可选）
```
> 命令行方式：
> ```bash
> git clone https://github.com/<你的用户名>/stock-value-app.git
> cd stock-value-app
> cp -r /path/to/stock-value-pwa/* .
> git add . && git commit -m "init stock value pwa"
> git push origin main
> ```

### 3. 开启 Pages
`Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save`

### 4. 访问
1–2 分钟后访问 `https://<你的用户名>.github.io/stock-value-app/`，手机"添加到主屏幕"即成 App。

### 5. 以后更新
改完代码推送后，**把 `sw.js` 里 `const CACHE = 'stockval-v2'` 的版本号 +1**，用户端会提示更新。

## 七、常见问题

**Q：输入代码没反应/报错？**
A：确认格式——A股 6 位数字、港股 1–5 位数字、美股字母。

**Q：评分高就能买吗？**
A：**不能**。评分是"估值 + 基本面 + 走势 + 风险 + 流动性"的量化参考，未包含行业景气、政策、管理层等因素。
高分也可能是"低估值陷阱"，务必人工复核。**股市有风险，入市需谨慎。**

**Q：为什么港股/美股没有 PB？**
A：腾讯免费接口对港股/美股不返回 PB，故估值维度仅按 PE 计算（App 已自动处理，不会算错）。

**Q：自选和基本面数据会丢吗？**
A：存在浏览器 localStorage，**清除缓存/换设备会丢失**，请定期用"导出备份"。
